# Codex Status

一个 macOS 菜单栏状态工具，用来显示 Codex 相关状态。

## App

- 名称：Codex Status
- 版本：1.0
- 系统要求：macOS 13.0+
- 架构：Apple Silicon arm64

## 使用方式

1. 下载或克隆本仓库。
2. 将 `Codex Status.app` 拖到 `Applications` 文件夹。
3. 双击打开应用。

## Included Files

应用包内包含状态监控相关 Python 脚本和图像资源。

## Notes

当前仓库保存的是已打包的 `.app` 应用包及其内置资源，不是完整源码工程。
